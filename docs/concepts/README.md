# Concepts

Use these short explanations at the point a result needs interpretation:

- [Gate and alternate routes](gate.md): which calls an approval boundary controls.
- [Approval and exact requests](approval.md): what one approval permits.
- [Decision and effect](decision-and-effect.md): why a receipt cannot prove occurrence.
- [Replay and trust](replay-and-trust.md): separate consistency from authority.
- [Glossary](glossary.md): key, policy, commitment, profile and coverage terms.

Seal is the gate. seal-check inspects supported receipts in a browser. seal-assurance-kit exposes terminal checks and host-oriented review tools. A reader can enter either checking path without installing the gate.

For versioned facts and known gaps, use [Evidence](../evidence/README.md). For an operational problem such as no approval prompt, start with [troubleshooting](../guide/when-something-looks-wrong.md), not the proof index.
