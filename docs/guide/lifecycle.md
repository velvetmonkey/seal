# Change, recover and remove protection

Operate from the project directory whose MCP configuration you intend to change. Inspect [status and coverage](what-is-protected-right-now.md) before and after changing a selection. Multiple configured servers and tool sets are supported; do not apply the dated one-route observation as a current limit.

For routine changes, review exact server/tool selections, remove the owned override for the affected server when appropriate, and apply the intended protection again. Restart the client as instructed and check an actual approval interaction. A reportable status exit is not proof that the client used the route.

Recovery is for incompatible state. Stop Claude Code first, preserve evidence, and use the documented archive operation rather than deleting state to force a clean appearance. Recovery retains journals, receipts and signing keys.

Unprotect removes the owned local override without editing the project's .mcp.json. Uninstall operates on an installed distribution, previews owned files/config changes and asks for confirmation. It retains history, approval journals, receipts and signing keys and preserves nonempty shared directories. A source checkout is not an installed distribution for this operation.

Use the [CLI reference](../reference/cli.md) for syntax and exits, [installation](../start/install.md) for release/update instructions, and [troubleshooting](when-something-looks-wrong.md) for drift or unreadable state. No real-client reconfiguration or uninstall was performed for this guide.
