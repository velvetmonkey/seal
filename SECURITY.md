# Security Policy

Report vulnerabilities through [GitHub private vulnerability reporting for
`velvetmonkey/seal`](https://github.com/velvetmonkey/seal/security/advisories/new).
That private advisory form is the canonical channel for vulnerabilities,
misleading security claims, and proof-story mismatches in the umbrella surface.
Do not put sensitive report details in a public issue.

## Channel status

Private vulnerability reporting is enabled for this repository (checked
2026-08-09), so the canonical advisory link above is a live private intake
channel. Include the affected repository and commit, a minimal redacted
reproduction, and whether the problem concerns proof source, runtime behavior,
release evidence, or a published claim.
