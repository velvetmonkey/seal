# Security Policy

This is a public umbrella repository.

Report vulnerabilities through [GitHub private vulnerability reporting for
`velvetmonkey/seal`](https://github.com/velvetmonkey/seal/security/advisories/new).
That private advisory form is the canonical channel for vulnerabilities,
misleading security claims, and proof-story mismatches in the umbrella surface.
Do not put sensitive report details in a public issue.

## Activation status

Private vulnerability reporting is currently disabled for this repository
(checked 2026-08-09). The repository owner must enable **Settings → Security →
Code security and analysis → Private vulnerability reporting** before the link
above becomes a working private intake channel. Until then, this repository does
not advertise an email fallback or claim that a private reporting channel is live.

Once the setting is enabled, include the affected repository and commit, a
minimal redacted reproduction, and whether the problem concerns proof source,
runtime behavior, release evidence, or a published claim.
